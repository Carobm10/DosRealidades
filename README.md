# DOS REALIDADES

Videojuego cooperativo 2D para dispositivos móviles desarrollado por **Media Create**.

**Concepto:** Dos jugadores. Dos perspectivas. Una sola solución.

## Información técnica

- Motor: Unity
- Versión: Unity 6000.6.4f1
- Plataforma principal: Android
- Orientación: Horizontal / Landscape
- Tipo de juego: Cooperativo para 2 jugadores
- Perspectiva: Top-Down
- Proyecto 2D

## Abrir el proyecto desde el computador

1. Abrir Unity Hub.
2. Ir a Projects.
3. Seleccionar Add.
4. Buscar la carpeta DosRealidades.
5. Seleccionar la carpeta raíz del proyecto.
6. Abrir utilizando Unity 6000.6.4f1.
